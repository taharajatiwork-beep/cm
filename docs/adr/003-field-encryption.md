# ADR 003: رمزنگاری فیلدهای حساس

**وضعیت:** پذیرفته  
**تاریخ:** ۱۴۰۵/۰۷/۲۱

## مسئله

شبا، x-token میزیتو، توکن/رمز پنل SMS و مشابه در دیتابیس و لاگ در معرض دید هستند.

## تصمیم

- `FIELD_ENCRYPTION_KEY` (Fernet) در production الزامی است؛ dev بدون کلید از مشتق `SECRET_KEY` استفاده می‌کند.
- مقادیر با پیشوند `enc1:` در همان ستون متنی ذخیره می‌شوند.
- API فقط ماسک برمی‌گرداند (مثلاً شبا: چهار رقم اول و آخر).
- لاگ ساختاریافته با ماسک توکن/رمز (قبلاً در `logging.py`).

## خارج از scope

- فایل JSON حساب سرویس گوگل روی دیسک می‌ماند؛ دسترسی OS و nginx جداگانه.

## خاموش‌کردن LLM بیرونی

`LLM_EXTERNAL_ENABLED=false` — بریف و خواندن اینسایت تصویر به مدل نمی‌روند.
