# واژه‌نامه UI (منبع اصلی نام‌گذاری کاربر)

جدول‌ها و APIهای فنی عوض نمی‌شوند؛ این سند فقط برچسب‌های فارسی در رابط و مستندات را یکدست می‌کند.

## «درخواست» — چند معنا در سیستم

| برچسب پیشنهادی UI | موجودیت فنی | مسیر / محل | توضیح کوتاه |
|-------------------|---------------|------------|-------------|
| **درخواست کار** | `work_request` | `/requests`, REQ-… | خواستهٔ مدیر به یک تیم؛ تبدیل به پروژه یا وظیفه. |
| **درخواست پرداخت** | `pm_payment_request` | `/perf/money` | شارژ پنل، هزینهٔ سوشال، سایر؛ جریان `requested` → `manager_ok` → `recorded`. |
| **درخواست قیمت** | `post_slots` + جریان قیمت | `/pricing` | درخواست تأیید قیمت/پست خودرو؛ مالی تأیید می‌کند. |
| **درخواست تبلیغ (میزیتو)** | `pm_mizito_request` (صندوق) | `/perf/campaigns` تب میزیتو | پیش‌نویس از میزیتو؛ ساخت کمپین پرفورمنس دستی. |
| **درخواست خودرو (کمپین)** | `pm_car_request` | پرفورمنس / سوشال | خودرو برای کمپین؛ نه درخواست کار. |
| **درخواست شعبه** | `case` نوع شعبه | پیام‌ها → درخواست‌های شعب | پروندهٔ `case`، نه `work_request`. |
| **درخواست موجودی** | `inventory_request` | موجودی | چک موجودی / انتقال / علاقه. |
| **درخواست تأیید (سازمانی)** | `approval_request` | `/my-work` (ریدایرکت از `/approvals`) | تأییدهای داخلی ادمین؛ با درخواست کار اشتباه نشود. |
| **درخواست HTTP** | — | تنظیمات اتصالات | فقط در راهنمای فنی میزیتو («از هدر درخواست»). |

## «کمپین» — دو موجودیت

| برچسب UI | جدول | کجا | کاربرد |
|----------|------|-----|--------|
| **موضوع گفتگو** | `campaigns` | پیام‌ها → بخش «موضوع گفتگو» | رشتهٔ گفتگو در ارتباطات؛ به `conversation.campaign_id`. |
| **کمپین پرفورمنس** | `pm_campaign` | `/perf/campaigns`, شیت، گزارش | اجرای تبلیغ (کد S… از `PmCampaignSequence` در DB؛ شیت «دفتر شماره» فقط export)، هزینه، پیامک، استوری؛ `project_id` اختیاری. |

در منو: «پرفورمنس → کمپین‌ها» همیشه **کمپین پرفورمنس** است. در پیام‌ها هرگز «کمپین» تنها ننویسید؛ **موضوع گفتگو** یا **کمپین پرفورمنس** (لینک به `/perf/campaigns/…`).

## پروژه

- **عنوان پروژه** (`work_project.title`): موضوع کار، مستقل از نام تیم.
- **تیم مجری** (`team_id` / `team_name`): برچسب جدا در لیست و کارت؛ در عنوان ادغام نمی‌شود.
- قرارداد قبلی UI (`عنوان — نام تیم` برای چند پروژه از یک درخواست) حذف شد؛ migration `0033` عنوان‌های قدیمی را تفکیک می‌کند.

## خط زمین (`spine`)

API: `GET /requests/{id}/spine` و فیلد `spine` در جزئیات پروژه — درخواست کار، پروژه، وظیفه، درخواست پرداخت، کمپین پرفورمنس (بدون ادغام جدول).
